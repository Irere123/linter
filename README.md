## Linter 4o

Linter is an interactive blog on Web development, Low-Level programming, and AI. 

## Tech Stack

- [Next.js](https://nextjs.org/) – framework
- [TypeScript](https://www.typescriptlang.org/) – language
- [Tailwind](https://tailwindcss.com/) – CSS
- [Turso](https://turso.tech/) – database
- [Better-Auth](https://next-auth.js.org/) – auth
- [Vercel](https://vercel.com/) – deployments
- [MDX](https://mdxjs.com/) - content
- [Motion/Framer-motion](https://motion.dev/) - Animations 


## Contributing

I love contributors! Here's how you can contribute:

- [Open an issue](https://github.com/irere123/linter/issues) if you believe you've encountered a bug.
- Start coding your cool thing
- Make a [pull request](https://github.com/irere123/linter/pull) to add new features/make quality-of-life improvements/fix bugs.
